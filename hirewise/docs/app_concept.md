# HireWise – App Concept

## 1. Overview

HireWise is a mobile marketplace that connects clients with skilled professionals, making hiring easier, faster, and more reliable, especially within a university environment.



## 2. Problem–Solution Fit

### Problem

* Difficulty finding trusted professionals
* Limited income opportunities for students
* Poor communication between clients and workers

### Solution

HireWise provides:

* Verified user profiles
* Search and filtering
* Real-time messaging
* Ratings and reviews



## 3. Target Users

* University students
* Skilled professionals (freelancers, technicians, tutors)
* Clients needing services



## 4. Core MVP Features

### 1. User Profiles

Professionals showcase skills, experience, and ratings
→ Solves visibility and trust issues

### 2. Search & Filter

Users can quickly find relevant professionals
→ Reduces time wasted searching

### 3. Job Posting

Clients describe their needs clearly
→ Improves clarity and efficiency

### 4. Messaging System

Direct communication between users
→ Solves coordination problems

### 5. Ratings & Reviews

Users rate services after completion
→ Builds trust and accountability



## 5. Constraints Handling

### Low Internet Usage

* Lightweight UI design
* Minimal data consumption

### Trust Issues

* Ratings and verified profiles

### Time Constraints

* Simple user flow (few steps to hire)



## 6. Unique Value Proposition

HireWise focuses on:

* University-based gig economy
* Low-data usage (optimized for campus Wi-Fi)
* Fast and simple hiring process



## 7. Feasibility

The app will be developed using:

* Flutter (frontend)
* Firebase (backend)

This makes the solution achievable within course requirements.



## 8. User Flow

Home
↓
Search / Post Job
↓
View Profile
↓
Chat
↓
Hire
↓
Review



## 9. Use Cases

* A student searches for a tutor and hires them
* A client posts a job and receives responses
* A professional creates a profile to showcase skills
* Users communicate through in-app messaging
* Clients leave reviews after service completion



## 10. Tools Used

* Figma – UI/UX design and wireframes
* GitHub – version control and collaboration
* Firebase – backend services
* ChatGPT (AI tool) – used for structuring documentation and refining ideas
