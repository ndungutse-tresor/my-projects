# Team Charter – HireWise

## 1. Team Purpose

To design and develop HireWise, a mobile marketplace connecting clients with skilled professionals.



## 2. Team Goals

* Deliver a functional MVP
* Conduct user research
* Design an intuitive interface
* Build a stable application
* Present the project clearly



## 3. Roles and Responsibilities

* Project Manager – planning and coordination
* UI/UX Designer – interface design
* Frontend Developer – app development
* Backend Developer – database and logic
* Research Lead – documentation



## 4. Communication Plan

* Daily communication via WhatsApp / Slack
* Meetings twice per week
* File sharing via Google Drive / GitHub



## 5. Workflow

* Break tasks into smaller parts
* Track progress regularly
* Collaborate and share feedback



## 6. Decision-Making

* Team discussion first
* Project Manager decides if needed



## 7. Conflict Resolution

* Open and respectful communication
* Focus on project goals
* Seek compromise when needed



## 8. Accountability

Each member is responsible for completing tasks on time and maintaining quality work.



## 9. Tools and Technologies

* GitHub (version control)
* Figma (UI design)
* Firebase (backend)
* Communication tools



## 10. Success Criteria (Phase 4)

* Functional MVP
* Easy-to-use system
* Active user interaction
* Clear and convincing presentation



## 11. Project Timeline (Weeks 1–9)

* Week 1–2: Field research and problem identification
* Week 3: App concept development
* Week 4: Wireframes and UI design
* Week 5–6: Frontend development (Flutter)
* Week 7: Backend integration (Firebase)
* Week 8: Testing and debugging
* Week 9: Final presentation preparation
